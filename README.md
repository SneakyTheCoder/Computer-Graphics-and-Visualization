# Computer-Graphics-and-Visualization

**How do I approach designing software?**  
  
This project has helped me to better understand how to implement 3D objects in a virtual space. This also gave me a better understanding of how the x, y, and z coordinate system can be used to alter objects in a way that may better fit the scene or achieved realism. This project also gave me insight into how projected lighting can be used to create an ambience for a scene. The design process I used in this project was aimed at ensuring I did not over-complicate my learning process. This involved modifying shapes and combining them to achieve similar hedge structure and tree shape that can be found in the scene. Once i had the initial structures made, I was able to easily replicate the hedges and layer them over each other to mimic the real hedges of the garden walkway. This was the same process for creating the shapes of the trees using two different shapes and having those two shapes placed in different areas of the scene. This design process also was broken into sections where we focused individually on textures, materials, lighting, and other aspects. This allowed me to build the scene gradually one piece at a time instead of focusing on the whole project entirely. This design process I can use professionally as its main focus is to break a large problem down into smaller, more manageable pieces.
  
**How do I approach developing programs?**  
My approach to developing the program was gradual trial and error. In order for the scene to look the way I needed it to I had to make small adjustments to the positions of objects so that they were placed correctly. This meant a lot of cycles of editing, recompiling, and visually inspecting the changes as I made them. This did help reinforce what I was learning as it required me to experiment with the different adjustable aspects of objects. This iteration played a big role when working on this project in almost every segment. This experimenting ultimately changed my approach as I was becoming much more comfortable in some areas while needing to practice more in others. Using reusable functions in this project also helped to keep different sections of code organized and easy to follow while also maintaining its modularity.

**How can computer science help me in reaching my goals?**  
This project and the assignments gave me much needed insight about computational graphics and visualization that I did not have before starting. These skills can easily be utilized in professional and educational work in the future. Learning about the different systems like materials, textures, lighting, and 3D coordinate systems allow me to better understand how computer code can be used to create visual scenes and not just textual or numerical output. The problem solving skills I also developed during this project can also be applied to other problems outside of computer graphics. The process of breading down large complicated problems and experimenting with different solutions is a great skill that can be used in almost any situation. Professionally, the skills I have developed help me to be a better programmer now that I have a basic understanding of designing, organizing, experimenting with solutions, and improving a much larger program. This project also helped with understanding how a user might interact with a visual program or scene, further solidifying my understanding of the user experience aspect.
