# Computer-Graphics-and-Visualization

How do I approach designing software?  
  
This project has helped me to better understand how to implement 3D objects in a virtual space. This also gave me a better understanding of how the x, y, and z planes can be used to alter objects in a way that may better fit the scene or achieved realism. This project also gave me insight into how projected lighting can be used to create an ambience for a scene. The design process I used in this project was aimed at ensuring I did not over-complicate my learning process. This involved modifying shapes and combining them to achieve similar hedge structure and tree shape that can be found in the scene. Once i had the initial structures made, I was able to easily replicate the hedges and layer them over each other to mimic the real hedges of the garden walkway. This was the same process for creating the shapes of the trees using two different shapes and having those two shapes placed in different areas of the scene. This design process also was broken into sections where we focused individually on textures, materials, lighting, and other aspects. This allowed me to build the scene gradually one piece at a time instead of focusing on the whole project entirely. This design process I can use professionally as its main focus is to break a large problem down into smaller, more manageable pieces.
